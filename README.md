# 📈 基金投资记录

个人基金投资记录工具，基于 Python + Streamlit 构建。

## 功能

- **基金管理**：添加、编辑、删除基金（代码、名称、类型）
- **交易记录**：记录买入/卖出操作（日期、金额、份额、净值、手续费）
- **自动统计**：
  - 总投入 / 已收回 / 在投金额
  - 收益 & 收益率（已清仓/持有中自动判断）
  - 持仓天数
  - 加仓/减仓次数及日期
- **可视化仪表盘**：
  - 组合总览 KPI
  - 基金收益对比
  - 持仓分布饼图
  - 单基金投资时间线
- **本地存储**：SQLite 数据库，数据归属用户

## 技术栈

| 组件       | 工具                    |
| ---------- | ----------------------- |
| 语言       | Python ≥ 3.9            |
| 框架       | Streamlit               |
| 图表       | Plotly                  |
| 数据处理   | Pandas                  |
| 数据库     | SQLite（内置）           |

## 快速开始

```bash
# 1. 创建 conda 环境
conda create -n touzi python=3.11 -y
conda activate touzi

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
streamlit run app.py
```

浏览器打开 http://localhost:8501 即可使用。

## 数据模型

交易纬度（`transactions` 表）：

| 字段     | 说明                     |
| -------- | ------------------------ |
| type     | `buy` 买入 / `sell` 卖出 |
| date     | 交易日期                 |
| amount   | 买入花费 / 卖出总价      |
| shares   | 份额（可选）             |
| nav      | 净值 / 单价（可选）      |
| fee      | 手续费                   |
| note     | 备注                     |

统计纬度（自动计算）：

| 指标       | 计算方式                           |
| ---------- | ---------------------------------- |
| 总投入     | 所有买入金额之和                  |
| 已收回     | 所有卖出金额之和                  |
| 在投金额   | 总投入 − 已收回                   |
| 收益       | 已收回 − 总投入                   |
| 收益率     | 收益 ÷ 总投入 × 100%              |
| 持仓天数   | 首次买入 → 今日（或末次卖出）      |
| 加仓次数   | 买入交易次数                      |
| 减仓次数   | 卖出交易次数                      |
